What this is

The same doc.player that rides on every DeltaVerse page, given a whole page of its own and an address bar. It fetches the URL, reads the prose out of it, and speaks it — highlighting each word as it is said, so you can follow along or look away.

What crosses, and what does not

No markup from the fetched page ever enters this one. The response is parsed by DOMParser, which builds an inert document — no browsing context, so its scripts never run and its images never load — and only text is taken out of it. Every element you see below was built here, with textContent, under a tag name chosen from a fixed list. Sanitising markup is a filter you can lose; extracting text is a boundary you cannot.

The request carries no credentials. Reading a page aloud must never hand your cookies to a host you only pasted.

The limit, stated plainly

A browser may only read another site if that site allows it (a CORS header). Most do not. Same-site URLs — anything on deltaverse.pythai.net — always work; for anywhere else, the page will say so rather than fail vaguely. There is no proxy behind this box, deliberately: a server that will fetch any URL you hand it is an open relay into everything it can reach.

Two ways to hear it, and why there are two

Read it — the player panel speaks the page with the browser's own synthesiser and lights each word as it is said. Instant, free, and nothing leaves your machine. But speechSynthesis output cannot be captured: no browser API hands you its samples, so there is nothing to save.

Render it — the text is sent to DeltaVerse and synthesised into a real Opus file that you can scrub, download and keep. That is a second rendering by a different engine, which is why it can sound different from what the panel just read you.

The rendering engine

espeak-ng, not the neural voices the DeltaVerse store uses. Those are piper, they sound better, and they run at about one times realtime on this host — a four-thousand-word page is twenty-five minutes of CPU, which is not something you can put behind a button somebody just pressed. espeak renders the same page in a couple of seconds. The cast here is mindX's own tuned set, and it includes OVERLORD: the LEADER voice's mass and reach combined with ANCIENT's refusal to ever raise a syllable, with a measured octave underneath it.

The store

Renders are kept and served as ordinary static files, so a page you have already rendered comes back instantly and costs nothing to make again. The cache holds 300 MB; past that the least recently played render is dropped first — recently used means recently listened to, not recently made, so the page everyone keeps coming back to is the one that survives.

Colophon

The instrument deck is DreamKnob. The JavaScript idiom — plain modules, no framework on the page, one behaviour per file — follows javascriptit, and the interaction pieces (drag, drop, resize and the other small reusable behaviours) follow mlodular.
